# 09 · 面试篇：把 AI 项目讲成可追问的证据

> **一句话**：面试不是背概念，而是「一句话开场 → 取舍展开 → 接住追问」。这一关把前六关的技术点压成 8 个专题的答题骨架。
> **前置**：至少通关第一关与第三关；第四关是 80% 生产感追问的来源。
> **产出**：每个专题能给出「观点 + 取舍 + 一个真实代码锚点」，并能扛住 2 轮追问。

## 统一答题骨架（每道题都套这个）

1. **一句话开场**：先给结论，不绕弯（例：「Agent = LLM + Tools + Memory + Planning，再加一层上下文工程」）。
2. **取舍展开**：为什么这么选、代价是什么、什么场景换方案。
3. **代码锚点**：能落到本仓库哪一行 / 哪个接口（如 `apps/backend/internal/tool/` 的 L0/L1/L2）。
4. **主动给追问点**：自己先说出「这块最容易被追问的是……」，把话语权拿回来。

> 版本口径统一看 [根 index.md 的版本基线](../index.md#版本基线唯一真源)：MCP 只说 `2026-07-28` 无状态，A2A 只说 `v1.0`，模型只说档位不照抄未核验型号。

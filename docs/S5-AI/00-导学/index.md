> **版本纪律**：所有型号 / 协议版本只引用 [根 index.md 的版本基线（唯一真源）](../index.md#版本基线唯一真源)，不在本关自创。

## 版本与口径提醒

- **模型型号是档位不是永久结论**：旗舰 / 性价比是分层，写代码前核对当期实列 ID（见根基线）。
- **协议版本**：MCP `2026-07-28`（无状态单端点）、A2A `v1.0`；不要把 MCP 说成有状态协议。
- **历史代际**（GPT-4o / Claude 3.5 / Qwen 2.5 等）只允许出现在「演进脉络」语境。
- 本仓库 JS 侧**只用 bun**，示例命令不得出现 npm / yarn / pnpm。

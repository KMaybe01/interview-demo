## 一、MCP 工具生态

MCP（Model Context Protocol）是 Anthropic 提出的标准化协议，让 Agent 能"插拔式"接入各种工具。

### 1. 浏览器自动化

| 工具 | 能力 | 成熟度 | 适用场景 |
|------|------|:------:|---------|
| **Playwright MCP** | 导航/点击/填写/截图/多浏览器 | ✅ 生产级 | Web 自动化测试、爬虫 |
| **Puppeteer MCP** | Chrome 自动化、PDF 生成 | ✅ 成熟 | Chrome 专属任务 |
| **Browserbase MCP** | 云端浏览器、会话管理 | 🚀 发展中 | 无头自动化 |

### 2. 数据与后端

| 工具 | 能力 | 适用场景 |
|------|------|---------|
| **PostgreSQL MCP** | Schema 查询、SQL 执行、事务 | 数据分析、自然语言查数 |
| **SQLite MCP** | 轻量数据库操作 | 本地应用、原型开发 |
| **Redis MCP** | 缓存读写、Pub/Sub | 实时数据、会话管理 |
| **Supabase MCP** | 完整后端即服务 | 全栈应用 |

### 3. 文件与代码

| 工具 | 能力 | 适用场景 |
|------|------|---------|
| **GitHub MCP** | PR/Issue/Code Review/搜索 | 代码管理、CI/CD |
| **Filesystem MCP** | 文件读写、目录操作 | 代码生成、文件管理 |
| **GitLab MCP** | GitLab 全功能 API | GitLab 生态 |

### 4. 搜索与知识

| 工具 | 能力 | 适用场景 |
|------|------|---------|
| **Brave Search MCP** | 网络搜索、获取结果 | 实时信息查询 |
| **Tavily MCP** | AI 优化搜索 | 深度调研 |
| **Sequential Thinking MCP** | 结构化推理 | 复杂问题分解 |

### 5. 通信与协作

| 工具 | 能力 | 适用场景 |
|------|------|---------|
| **Slack MCP** | 消息/频道/搜索 | 团队协作 |
| **Notion MCP** | 页面/数据库操作 | 知识管理 |
| **Linear MCP** | Issue/项目管理 | 开发流程 |

### MCP 工具选型速查

| 场景 | 推荐组合 |
|------|---------|
| **通用 Agent** | Brave Search + Filesystem + GitHub |
| **数据密集型** | PostgreSQL + Redis + Supabase |
| **Web 自动化** | Playwright + Browserbase |
| **企业协作** | Slack + Notion + Linear |

## 三、AI Coding 工具矩阵

AI 编程助手正从"代码补全"向"自主编程 Agent"演进。

### 工具代际演进

```
Gen1（补全） → Gen2（对话） → Gen3（Agent） → Gen4（自主）
Copilot        Cursor         Claude Code      Devin
TabNine        Windsurf       OpenHands        未来形态
```

### 主流工具对比

| 工具 | 代际 | 核心能力 | 技术原理 | 价格 |
|------|:----:|---------|---------|------|
| **[Cursor](https://cursor.com)** | Gen2 | IDE 内 Agent + 多文件编辑 | Claude/GPT + 索引 | $20/月 |
| **[Claude Code](https://claude.ai)** | Gen3 | 终端 Agent 全栈能力 | Claude + 文件系统 | API 计费 |
| **[GitHub Copilot](https://copilot.github.com)** | Gen1 | 行内补全 + Chat | Codex + RAG | $10-39/月 |
| **[Windsurf](https://codeium.com)** | Gen2 | 上下文感知补全 | 专有模型 | 免费/$15 |
| **[Cline](https://cline.bot)** | Gen3 | 开源 Agent + 终端 | 多模型支持 | 免费(自备Key) |
| **[Augment](https://augmentcode.com)** | Gen2 | 全仓库理解 | Code Graph | 邀请制 |

### 选型建议

| 场景 | 推荐 | 理由 |
|------|------|------|
| **日常编码** | Cursor | IDE 体验最好，Agent 能力强 |
| **复杂重构** | Claude Code | Agent 能力最强，多文件操作 |
| **轻量补全** | Copilot | 兼容性最广，补全体验好 |
| **预算有限** | Windsurf/Cline | 免费或低成本 |
| **最佳组合** | Cursor + Claude Code | 日常 + 复杂任务互补 |

## 六、面试高频考点

### Q: 你了解哪些 AI 工具和平台？

**参考回答**：

> 我主要关注三个层面：
> 1. **模型服务**：OpenAI、Anthropic、DeepSeek，根据场景选型
> 2. **开发框架**：Vercel AI SDK（前端首选）、LangChain（复杂编排）
> 3. **应用平台**：Dify（企业级）、FastGPT（知识库）
>
> 工具层面，日常使用 Cursor + Claude Code 组合，MCP 协议关注 Playwright 和 GitHub 两个 Server。

### Q: MCP 协议解决了什么问题？

**参考回答**：

> MCP 解决了"工具标准化接入"问题。类似 USB-C 统一了设备接口，MCP 统一了 LLM 与工具的通信方式。
>
> 核心价值：
> 1. **一次开发，多处复用**：MCP Server 可在 Claude Desktop、Cursor 等多个宿主使用
> 2. **动态发现**：Agent 运行时自动发现可用工具
> 3. **生态繁荣**：社区共建工具市场，降低开发门槛

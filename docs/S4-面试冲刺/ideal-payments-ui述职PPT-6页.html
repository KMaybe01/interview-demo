01 ｜ 项目业务全景

这个系统是做什么的？

企业网银的"钱袋子中枢"——企业客户的每一笔花钱、收钱、管钱，都要经过这套系统。

→

出 · 付款

给供应商汇款（本币 / 跨境）、公司账户间调拨、批量发薪、缴水电费账单……
单据提交后统一进入出账总账本集中监控。
配套：收款人名册 · 快捷模板 · 每月自动扣划的周期付款 · 止付追回（风险紧急拦截）
←

入 · 收款

向客户单笔或批量托收货款，回款统一沉淀进收款总账本。
配套：付款人档案 · 快捷收款模板——维护一次、处处可用，前台少录重
✓

管 · 审批

监管要求：每笔交易必须"经办 + 复核"双人把关，一人提交、另一人审批，防单人操控资金。
审批员可集中审批或页面内就地处理，勾选多条一键批量通过 / 驳回
一笔交易的完整旅程（以付款为例）
① 经办提交
财务人员录入付款单
→
② 待审批
钱不会直接扣，进入待审池
→
③ 复核把关
审批人通过 / 驳回
→
④ 落地
通过 = 银行记账清算
驳回 = 记原因、可追溯
谁在用：企业财务（提单）+ 审批人（复核）｜ 全流程满足审计要求

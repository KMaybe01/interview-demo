### 项目二：AeMS — 企业级综合网络管理系统
**技术栈：** Angular 22 + TypeScript 6 + NG-ZORRO 21 + OpenLayers 10.x + ECharts 5.x + WebSocket (STOMP) + Go + Gin

> **背景**：面向**十万级 Small Cell 网元设备**的综合智能网管中枢，覆盖设备监控、智能告警、日志分析、安全审计全链路，需处理 **1000+ QPS** 告警并发与 **十万级设备** GIS 拓扑渲染。

- **S（情境）**：十万级设备实时监控，原系统在万级并发下卡顿严重
- **T（任务）**：支持 **1000+ QPS** 高并发实时监控 + 十万级 GIS 拓扑渲染

**我的行动与成果：**

- **GIS 十万级点位四重优化：**BBOX 视口裁剪仅保留可见点位, Cluster 聚类聚合（distance=40px), dataCache 全量缓存（zoom+extent 作为 key), moveend 惰性刷新 + RAF 节流将渲染量降至百级，帧率 <10fps → 60fps。

- **高并发实时告警中枢**：抽象统一的 Transport 传输层接口，设计**三级降级链路（WebSocket → SSE → 短轮询）**。引入**背压控制**、**消息合并**、以及**心跳保活机制，**配合前端 **RAF 双缓冲渲染**，确保在 **1000+ QPS 的高并发告警冲击下，界面交互仍维持在 60fps 的全帧率水平**。
- **LRU 路由页面缓存**：实现 Angular RouteReuseStrategy 四阶段生命周期（shouldDetach → store → shouldAttach → retrieve），LRU 淘汰自动销毁最久未访问，滚动位置异步恢复，模块级隔离（切换大模块时清理其他模块缓存）→ 页面切换性能提升 **60%**
- **企业级动态权限与会话安全**：设计基于树形常量的权限码映射自动生成方案，构建**三层联动控制链路（菜单递归过滤、路由 Guard 拦截、按钮级 ACL 控制）**，从根本上闭环了前端权限越权路径，**权限越权漏洞发生率降低 90%**。
- **精确 Loading 状态管理**：设计**请求级粒度的状态追踪方案**，拦截器通过 method-path 动态标记请求。按钮组件自动关联其对应的请求状态，避免了全局或区域 Loading 混淆，**实现了组件级细粒度反馈并消除了无意义的全局遮罩**。

### 项目三：@axyom-ui 企业级内部组件库搭建
**技术栈：** Angular 22 + TypeScript 6 + NG-ZORRO 21 + RxJS 7 + ng-packagr + Vitest

> **背景**：企业内部多个 Angular 项目存在大量重复的表格和表单业务逻辑，每个项目都需单独封装分页/排序/选择等表格功能以及手写表单模板代码，维护成本高、开发效率低。

- **S（情境）**：多个 Angular 项目重复封装表格和表单逻辑，代码复用率低，维护成本高
- **T（任务）**：以 Library 形式搭建统一的企业级内部组件库，覆盖表格与表单两大高频场景

**我的行动与成果：**

- **状态管理：** 深度采用 **Angular Signals API**（利用 signal、computed、model），替代传统 RxJS 模式管理分页、排序、选中行等 UI 状态，依靠**依赖图自动追踪**实现组件的**局部精准更新**。
- **声明式设计：** 提供极简的 API 设计，最简配置仅需 cols（列定义）与 rows（行数据）两个入参。支持**渐进式增强**，可按需无缝开启分页、排序、选择、树形、虚拟滚动等扩展功能。
- **数据适配：** 内置**前端分页、后端分页、不分页的三态分页设计**，排序策略可根据当前分页模式自动适配。经内部业务项目实践，**减少了约 80% 的表格相关业务代码量**。
- **分层架构：** 采用**五层架构设计（基础设施→基类→组件→调度→容器）**，逻辑边界清晰。
- **动态分发：** 引入注册表模式，结合 **NgComponentOutlet 与 FormUnitRegistryService** 实现运行时的动态组件分发。支持通过单行 register() 快速扩展 20 余种组件类型。
- **校验机制：** 内置 10 种自定义验证器（含 IP、URL、手机号、身份证、BigInt 超大数值及跨字段联动等）。跨字段验证通过**闭包延迟订阅机制**设计，有效避免了依赖循环与死锁问题。

- **CI/CD 流水线：** 配置 **GitLab CI 条件触发机制**，仅 main 分支 + package.json 变更触发 test→build→npm publish 流水线自动发布流水线，保障发布规范性。
